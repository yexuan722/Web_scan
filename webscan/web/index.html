关于

WebScan 1.0 · Web 漏洞扫描系统（课程课题 30）

能做什么

  • 同源爬取站点结构（URL、表单、参数），默认限速 6 请求/秒
  • 被动分析：安全响应头、Cookie 属性、版本泄露、目录列表、报错信息、注释、混合内容、表单安全
  • 只读探测：Git / .env / 备份包等敏感文件（带内容指纹，避免 404 误报）、CORS 配置
  • 主动 PoC（需显式开启）：反射型 XSS、错误型 SQL 注入、路径穿越、开放重定向，全部二次验证
  • 健康评分：noisy-OR 模型，每条扣分可复算、可解释

不做什么

  • 不利用漏洞、不写入、不删除、不爆破密码
  • 不扫描未授权目标；任务必须勾选授权确认
  • 不实现绕过 WAF 的对抗性混淆

风险模型

P = 1 - Π(1 - base[severity] × confidence)，健康分 = 100 × (1 - P)。 base 取值：严重 0.35 / 高危 0.20 / 中危 0.08 / 低危 0.02。
